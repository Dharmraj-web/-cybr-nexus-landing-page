# IIT Bombay Techfest Student Ambassador — Task 2 Submission Guide

## Project
CYBR//NEXUS — Beyond Human (Task 1 upgraded with interactive 3D).

## What changed
- Added a real-time Three.js 3D cybernetic core to the hero visual.
- Added metallic faceted geometry, glowing energy nucleus, sensor lenses, orbital rings, floating nodes and star particles.
- Added drag-to-rotate and scroll-to-zoom controls.
- Added responsive canvas resizing and reduced-motion support.
- Preserved Task 1 sections, colors, typography and interactions.

## Local testing
Run a local server in this folder: `python -m http.server 8000`, then open `http://localhost:8000`. The Three.js module loads from jsDelivr, so an internet connection is required.

## GitHub Pages update
Upload/commit all files in this folder to the same Task 1 repository, including the new `three-scene.js`. Keep the import map and module script in `index.html`. GitHub Pages will serve the update from the root.

## Demo recording (60–90 seconds)
1. Introduce CYBR//NEXUS Task 2 — Build in 3D.
2. Show the 3D object and orbital elements.
3. Drag to rotate the core from multiple angles.
4. Scroll to zoom in and out.
5. Show the full landing page sections to establish continuity with Task 1.
6. Resize to mobile width and show the 3D canvas adapting.

## Before submission
- Confirm the 3D scene loads on the published GitHub Pages URL.
- Test mouse drag, touch drag, and zoom.
- Check browser console for errors.
- Record a fresh Task 2 demo and upload it to Google Drive with `Anyone with the link — Viewer`.
- Submit the repository URL and the new demo URL in the Task 2 form.
