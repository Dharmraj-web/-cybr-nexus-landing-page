# Submission guide — do these steps in order

## 1. Preview and test
1. Extract the ZIP folder.
2. Open `index.html` in Chrome or Edge.
3. Scroll through every section and test all three module buttons.
4. Make the browser narrow (or use DevTools → Toggle device toolbar) and test the mobile menu.
5. Fix anything you notice before recording.

## 2. Publish to GitHub
1. Sign in to GitHub and click **New repository**.
2. Repository name: `cybr-nexus-landing-page`.
3. Set visibility to **Public**. Do not add a README if you are uploading the files already included here.
4. Create the repository.
5. On the new repository page, choose **Add file → Upload files**.
6. Upload `index.html`, `style.css`, `script.js`, `README.md`, and `SUBMISSION_GUIDE.md` from this folder (upload the files, not the ZIP itself).
7. Commit the changes.
8. Open the repository and confirm the files are visible without signing in. Copy the repository URL.
9. Optional: enable GitHub Pages from **Settings → Pages**, select the `main` branch and `/ (root)`, then save. Wait for the published URL to appear and test it.

## 3. Record a concise demo (45–90 seconds)
Suggested order:
- 0–10 sec: show the landing page hero and animated visual.
- 10–25 sec: scroll to Protocol and show the three feature cards.
- 25–40 sec: click Neural Sync, Optic Overdrive, and Kinetic Engine; show the content/art changing.
- 40–55 sec: show the diagnostics dashboard and final call-to-action.
- 55–70 sec: resize to mobile width and demonstrate the hamburger menu.
- End by showing the public GitHub repository briefly.

Use Windows Snipping Tool screen recording or Xbox Game Bar (`Win + Alt + R`) if available. Speak clearly, keep the cursor deliberate, and avoid showing personal notifications or private tabs.

## 4. Share the video through Google Drive
1. Upload the video to Google Drive.
2. Right-click the video → **Share**.
3. Under **General access**, change **Restricted** to **Anyone with the link**.
4. Ensure the role is **Viewer**.
5. Click **Copy link** and test it in a private/incognito browser window.

## 5. Final submission
Submit both:
- **GitHub repository:** `https://github.com/YOUR-USERNAME/cybr-nexus-landing-page`
- **Demo video:** paste the Google Drive link you copied.

Replace `YOUR-USERNAME` with your real GitHub username. Do not submit placeholder links. Never claim a feature is live until you have tested it.
